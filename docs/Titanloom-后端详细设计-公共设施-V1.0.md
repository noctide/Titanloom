# Titanloom · 后端详细设计 · 公共设施（文件 · 审计 · 通知与待办）

> 版本：V1.0｜日期：2026-10-17｜状态：维护者已确认（设计页 sketch-backend-facilities v1，I 节 7 处 2026-10-17 "可以"）；数值为起点值，M1 实测后校准，写成业务参数或部署参数。
> 定位：M1 底座模块 `facilities` 的后端设计：文件、审计、通知、待办收件箱，以及文案与搜索索引的存放。
> 依据：后台治理 11.1、11.3、11.5、12.2、12.5；Shell 9、9.1；能力契约 9.4；国际化规范；集成与消息通道；《后端详细设计 · 总图》G、I、J；ADR-021、ADR-026、ADR-029。

## 1. 管什么、不管什么

| 对象 | 管 | 不管 |
| --- | --- | --- |
| 文件 | 字节、版本、检查、派生物、按引用鉴权下载、用量与配额、隔离区、清理 | 文件属于哪条业务记录（引用模块登记）；谁能看由引用它的对象决定 |
| 审计 | 只追加的管理与高影响操作记录 | 运行日志、被拒绝的请求（ADR-027） |
| 通知 | 站内信、实时角标、按收件人语言渲染、合并限频；外部渠道交集成中心 | 通道地址与密钥、告警规则 |
| 待办 | 统一收件箱的展示副本 | 办没办完（所属模块说了算，Shell 9） |
| 文案 | 语言资源、术语表与同义词、语言包版本（国际化规范） | 对象自己的中英名称 |
| 搜索索引 | `search` 分区（总图 9、能力契约 9.5） | 各模块数据本身 |

## 2. 文件

流程：临时区分片上传 → 检查（大小、真实类型、格式）→ 登记文件编号、版本与内容指纹 → 业务引用"文件 + 第几版" → 后台派生（缩略图轻道；视频转码、3D 压缩重道）→ 下载时按引用鉴权。

-   检查没过进隔离区，不能下载；撤回一人可做，放行须第二位管理员（后台治理 11.1）。
-   业务只引用文件编号与版本，不传服务器路径（能力契约 9.4）；换文件 = 新版本。
-   **谁能看文件 = 谁能看引用它的对象**；同一字节多处引用各自鉴权。
-   下载由主程序鉴权后经门卫发送字节；图片以外一律以附件方式下载，禁止内容嗅探。
-   **按内容指纹存一份**（I1）：相同字节只占一份磁盘，去重不合并授权。没人引用的文件宽限 7 天后再确认一次才清，上传未完成的不算孤儿；原文件清除时派生物一起清。
-   **上限与检查**（I2）：单文件默认 50 MB，视频与 3D 模型 200 MB（业务参数）。首期不装杀毒软件，只做真实类型识别与格式校验，拒收可执行文件、脚本与带宏的 Office 文件；隔离区与存储页标明"未做病毒扫描"，检查接口保留供以后接入。
-   **不做匿名公开链接**（I7）：复制的链接对方打开也要登录并有权限；对外提供文件走导出与人工发送。
-   用量按部门 / 项目计，超额处理按后台治理 9.3。

## 3. 审计

-   写什么按后台治理 12.2；与业务改动同一事务写入，审计写不进去改动不成立。密码、密钥、无必要的业务明细不写，只写前后摘要（例："时薪：已修改"）。
-   **只追加、带指纹链**（I3）：应用数据库账号对审计表只有插入与读取权限；每条记录带上一条的指纹，每天另存当天最后一条的指纹；体检每周校验全链，链断即报。
-   谁能看：平台管理员与安全审计员按授权范围；部门负责人看本部门相关；各对象"记录"标签只列与之相关的。查看审计本身也记一笔。
-   保留 3 年（业务参数，改短需第二位管理员），到期按月归档为文件，不在库里逐条删除。

## 4. 通知

流程：模块在事务内发出"有事"（类型、对象、收件人、严重度、文案键与参数）→ 展开收件人并去掉看不到该对象的人 → 按收件人语言渲染并记语言包版本 → 合并与限频 → 站内信与实时角标 → 按个人设置交集成中心往外发。

-   只放必要摘要与站内链接，点进去再鉴权；不放业务明细、密钥与长期附件链接（后台治理 11.3）。
-   每条通知有去重键，重试与重投不重复；投递失败与业务失败分开记录。
-   **合并与免打扰**（I4）：同一收件人同一去重键 5 分钟内合并为一条并计数；22:00–07:00 发往个人外部渠道的先暂存，07:00 合并发送；站内信不受影响，严重告警不受限。个人可按类别选只站内或站内 + 外部，可把免打扰时段调窄；**必读公告、要我审批、账户安全**三类不能关闭站内。

## 5. 待办

-   模块在事务内发出"新待办 / 换办理人 / 已办完"事件，收件箱据此维护展示副本（标题文案键、来源、期限、能否批量、办理入口）；在抽屉里办理调用的是模块登记的办理能力，收件箱不自己改状态。
-   **组待办先办先得**（I5）：发给一组人时每人一条，谁先办完算谁，其余显示"已由 X 处理"；首期不做认领。
-   稍后处理只是本人显示偏好；只有模块声明可批量的类型才能批量办理；办理人离职或失去权限由模块重新计算办理人，交接清单列出其未办待办。
-   来源模块不可用时显示"来源暂不可用"，不显示为 0；每晚向各模块对账。"我发起的"同样是副本。

## 6. 文案与搜索索引

-   文案按国际化规范存放：每个键中英各一份，有草稿与已发布；发布生成不可变语言包版本（按语言、按模块分块），改文案须发布才生效。术语表一词一行，带"也叫"，同时供搜索同义词扩展。
-   搜索索引单独放在 `search` 分区，可随时从各模块重建，**不进备份**（I6）；恢复后自动排一件重建任务。

## 7. 保留期（I6）

| 数据 | 保留 |
| --- | --- |
| 审计 | 3 年，到期按月归档为文件 |
| 站内信 / 通知 | 180 天 |
| 已完成待办的副本 | 1 年，更早的到所属模块查 |
| 没人引用的文件 | 7 天宽限后清 |
| 临时区未完成上传 | 24 小时 |
| 语言包旧版本 | 最近 20 版；被可视化发布版钉住的不删 |

## 8. 对外接口

`facilities.api`：文件（开始上传、完成、查状态、登记 / 取消引用、按引用鉴权下载、取派生物）· 审计（事务内写入、按对象查）· 通知（事务内发出、查我的、标已读）· 待办（事务内发出新待办 / 换人 / 办完、登记待办类型）· 文案（登记键清单、后端按语言取字、前端按版本下载语言包）· 搜索（能力契约 9.5）。

## 10. 给执行 Agent 的技术细节

**表（schema `facilities`）**：`asset`、`asset_version`、`blob`（sha256 主键、ref_count、orphan_since）、`asset_ref`、`derivative`、`upload_session`、`usage_counter`、`audit_event`（按月分区，INSERT only，prev_hash / hash）、`audit_anchor`、`notification`（unique recipient_id + dedupe_key）、`notify_pref`、`outbound_hold`、`todo_type`、`todo_item`、`todo_assignee`、语言资源与术语表（国际化规范）；`search.search_doc`。

**文件**：分片 8 MiB；libmagic 嗅探；按类型格式校验（Pillow、openpyxl 只读、zip 解压比上限 100）；拒收 PE / ELF / 脚本与 .xlsm / .docm；blob 存 `assets/ab/cd/<sha256>`；下载 `X-Accel-Redirect` + `X-Content-Type-Options: nosniff`。参数 `files.maxBytes`、`files.maxBytesMedia`、`files.orphanGraceDays`、`files.tmpTtlHours`。

**审计**：hash = sha256(prev_hash ‖ 规范化 JSON)；事务内以链尾锁串行化，目标 ≥ 200 条 / 秒（M1 实测）；每日 00:05 写锚点；每周体检校验全链；月归档导出 JSONL.gz 后分离分区。契约 audit-event 新增 prevHash / hash。

**通知**：`INSERT … ON CONFLICT (recipient_id, dedupe_key) DO UPDATE SET merged_count = merged_count + 1`（窗口 `notify.mergeWindowMin` 5）；夜间暂存 `notify.quietFrom/To`；外发经集成中心 DeliveryRoute。

**待办**：事件 `todo.opened` / `todo.reassigned` / `todo.closed`，按 sourceRef + 事件版本幂等；组待办关闭时其余置 done_by_other；每晚对账。

**备份**：排除 `search` 分区；恢复后排重建任务（重道，按模块分批）。

**契约**：asset-version、asset-ref、notification、notify-pref、todo-item；audit-event 加指纹链字段；测试 `test_contracts_part11.py`。

**验收要点**：同字节两次上传只一份 blob、两处引用各自鉴权；检查失败进隔离不可下载；孤儿 7 天前不清、上传中不算孤儿；审计与业务同成同败；应用账号改删审计被拒；篡改一条后体检报链断；看不到对象的人收不到通知；5 分钟内同类合并；夜间外部渠道延到 07:00；不可关类别关不掉；组待办一人办完其余显示已由他处理；来源不可用不显示 0；无匿名下载链接。
